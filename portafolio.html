Clon de Red Social Distribúido

La Arquitectura

El objetivo principal fue diseñar un ecosistema backend que soportara concurrencia y escalabilidad, emulando el comportamiento de plataformas como Twitter. En lugar de un monolito tradicional, se implementó una arquitectura orientada a microservicios.

Implementación Técnica

Se utilizó Nginx como API Gateway y Load Balancer para dirigir el tráfico a las distintas instancias. La comunicación asíncrona (como la publicación de mensajes) se manejó a través de colas de mensajes con RabbitMQ. Todo el entorno fue orquestado utilizando contenedores de Docker para asegurar la consistencia entre desarrollo y producción.

Stack Principal

  • ✔️ Node.js (Lógica de negocio)
  • ✔️ Docker (Orquestación)
  • ✔️ RabbitMQ (Message Broker)
  • ✔️ Nginx (Balanceo de carga)

Hardware / IoT ESP32 C++

Cortina de Agua Automatizada

Desarrollo Electrónico

Un sistema físico interactivo diseñado para sincronizar rítmicamente el flujo de agua. El núcleo de hardware está compuesto por microcontroladores ESP32 comunicándose mediante el protocolo I2C bajo una topología Maestro-Esclavo, logrando alta precisión en las instrucciones.

Control y Software

A través del microcontrolador principal, se gestionan las señales hacia 11 electroválvulas independientes. El sistema cuenta con una interfaz web alojada en el propio ESP32 que permite al usuario administrar las secuencias y ritmos de apertura de forma remota.

Componentes

  • ✔️ ESP32 (Maestro/Esclavo)
  • ✔️ Protocolo I2C
  • ✔️ Válvulas Electrónicas
  • ✔️ C++ (Arduino IDE)

Simulación de Control Secuencial de Motores

Diseño de Circuitos y Lógica

Para validar la viabilidad de sistemas físicos complejos antes de su construcción, desarrollé simulaciones detalladas en Proteus. Este proyecto se centró en un controlador secuencial capaz de gestionar múltiples motores basados en lecturas de sensores en tiempo real.

Programación a Bajo Nivel

Programando la lógica central en C++ mediante microcontroladores de la familia Arduino, el sistema evalúa entradas físicas y emite instrucciones de potencia. Un ejercicio integral de mecatrónica y flujo de control.

Herramientas

  • ✔️ Proteus Simulator
  • ✔️ Arduino / C++
  • ✔️ Sensores y Relés
